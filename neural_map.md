# Neural Map

## Subsystems & Architecture

- **SKILL.md**: Unified frontend engineering & design system master contract.
- **PICKER.md**: Interactive test harness specification for multi-variant prototyping.
- **reference/**: 35+ specialized discipline playbooks (`craft-floor.md`, `audit.md`, `critique.md`, `polish.md`, `new-work.md`, `animate.md`, `clarify.md`, `distill.md`, etc.).
- **scripts/**: Automation engines and detectors:
  - `detector/`: Antipattern detectors, AST/regex rules, visual checks.
  - `live/`: Live browser inspection, DOM capture, framework adapters (TanStack, etc.).
  - `lib/` & `data/`: Design token palettes, font matching, prompt embedding.
